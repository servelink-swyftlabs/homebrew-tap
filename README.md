# homebrew-tap

Homebrew formulas for [serve](https://servelink.cc) — ask your AI to share what
you just made.

```
brew install servelink-swyftlabs/tap/serve
```

The formula installs the same client published to npm as `@servelink/serve`; its
archives come from
[servelink-swyftlabs/serve-dist](https://github.com/servelink-swyftlabs/serve-dist).

Docs, the MCP configuration and issues live in
[servelink-swyftlabs/serve-mcp](https://github.com/servelink-swyftlabs/serve-mcp).
